II. Linux and Programming Tools
---------------------------------

* `Cygwin <https://www.cygwin.com>`_ on Windows.
* `Windows Subsystem for Linux (WSL2) <https://learn.microsoft.com/en-us/windows/wsl/install>`_ on Windows.
* `Oracle VM Virtual Box <https://www.virtualbox.org>`_ and `Ubuntu <https://ubuntu.com>`_ on Windows.
* `VSCode <https://code.visualstudio.com>`_ on Windows, Linux, and MacOS.
* `GitHub <https://github.com>`_
* `Git <https://git-scm.com>`_ for version control.
* `putty <https://www.putty.org>`_, `WinSCP <https://winscp.net/eng/index.php>`_, `FileZilla <https://filezilla-project.org>`_  for remote access to HPC systems.
* `MobaXterm <https://mobaxterm.mobatek.net>`_ for remote access to HPC systems.
* `Jupyter Notebook <https://jupyter.org>`_ and `Google Colab <https://colab.research.google.com>`_
* `Google Colab <https://colab.research.google.com>`_ for running Python codes online.

Documentation Tools:
* `Markdown <https://www.markdownguide.org>`_ and `Sphinx <https://www.sphinx-doc.org>`_ for documentation.
* `Read the Docs <https://readthedocs.org>`_ for hosting documentation.
* `LaTeX <https://www.latex-project.org>`_ for writing scientific documents.
* `Overleaf <https://www.overleaf.com>`_ for writing scientific documents online.
* `ShareLaTeX <https://www.sharelatex.com>`_ for writing scientific documents online.
* `Vi <https://www.vim.org>`_ and `Emacs <https://www.gnu.org/software/emacs/>`_ for text editing and programming.
